# Khalid Elnuor — Unofficial Payment Summary Generator

نظام ويب خفيف يعمل مباشرة في المتصفح، بدون Node.js أو Termux أو قاعدة بيانات.

## المزايا
- إدخال اسم العميل ورقم الحساب والخدمة.
- المبلغ بالعملة الأصلية + المبلغ بالدولار.
- سعر صرف قابل للتعديل.
- حساب الإجمالي تلقائياً.
- حالات: Pending / Paid / Cancelled.
- معاينة مباشرة بتصميم احترافي.
- طباعة أو حفظ كـ PDF من المتصفح.
- يعمل من الهاتف ويمكن رفعه إلى GitHub Pages.

## مهم
هذا النظام مخصص لإنشاء **كشوف سداد/ملخصات غير رسمية**. لا ينبغي استخدامه لإنشاء فاتورة رسمية مزعومة أو إيصال دفع مزيف أو مستند يوحي بأنه صادر عن Starlink أو أي شركة أخرى. يظهر في التصميم بوضوح أنه UNOFFICIAL.

## التشغيل
1. ارفع الملفات الثلاثة إلى مستودع GitHub.
2. فعّل GitHub Pages من Settings → Pages.
3. اختر Branch: main و Folder: /root.
4. افتح الرابط الذي يعطيه GitHub.

لا يحتاج المشروع إلى npm أو خادم.
